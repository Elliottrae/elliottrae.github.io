# Portfolio: Elliott Owens

Single-file static site (`home.html`). No build step.

## Publish with GitHub Pages
1. On github.com, create a new public repository named `YOUR-USERNAME.github.io` (this gives you the URL `https://YOUR-USERNAME.github.io`).
2. Upload `home.html` and this README (Add file > Upload files), then commit.
3. Go to Settings > Pages. Under "Build and deployment", choose "Deploy from a branch", branch `main`, folder `/ (root)`, and Save.
4. Wait 1-2 minutes, then open your URL.

## Before you publish
- Verify every number against your records (see the notes in the chat: employees trained, returning-client rate).
- Add freelance design images in the "Design background" section.
- Add the URL to your LinkedIn and resume header.
